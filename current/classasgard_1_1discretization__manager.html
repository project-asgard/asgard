Detailed Description

template<typename precision = default_precision>
class asgard::discretization_manager< precision >

Wrapper around several aspects of the pde discretization.

Assumes ownership of the loaded PDE and builds the sparse grid and operators. The current state is set to the initial conditions and time is set to 0 (if a restart file is provided the state and time are loaded form the file).

Time integration can be performed with the advance_time() function.

template<typename precision = default_precision>
bool asgard::discretization_manager< precision >::advance_time ( int64_t  num_steps = -1)
inline

integrate in time for the given number of steps, -1 means until the end

Parameters
num_stepsindicates the number of time-steps to perform.

If num_steps is negative, integration proceeds until the end-time.

If num_steps is more than the number of remaining steps, integration will not exceed the final time and will stop as soon as end-time is reached.

If solving for a steady state, num_steps has no effect.

returns true on success or false if running with -safe-step and inf or nan was detected

Example usage:

int64_t const stride = 10;
while (disc.remaining_steps() > 0
and disc.advance_time(stride)){
// the while loop will try to advance for 10 time-steps
// if safety is enabled and a step fails, the loop will exit
// safe a snapshot with filename snapshot_10, snapshot_20 ...
disc.save_snapshot("snapshot_" + std::to_string(disc.current_step()));
}
disc.save_final_snapshot();
