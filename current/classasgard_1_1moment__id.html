Detailed Description

Strong type for the moment ID.

Wrapper around an int that can be used to access a specific moment from asgard::momentset and asgard::momentset_gpu

The moment-id is obtained by calling pde_scheme::register_moment and should not be created directly from an int, let ASGarD do the correct initialization.
