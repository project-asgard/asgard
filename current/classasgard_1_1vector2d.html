Detailed Description

template<typename T>
class asgard::vector2d< T >

Wrapper around std::vector, but providing 2d organization of the data.

The data is divided into contiguous strips of fixed size. The class provides easy access to individual strips, without the tedious i * stride + j notation and with easy check for sizes.

Note: while this is similar to a matrix, there is no notion of rows or column and the data is not meant to represent a linear transformation.

Allows access to the stride(), num_strips(), check for empty() and access to alias to any strip with the [] operator.

Since this container owns the data, we can also append more strips and/or clear all the existing data.
