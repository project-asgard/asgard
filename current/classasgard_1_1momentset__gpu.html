Detailed Description

template<typename P>
class asgard::momentset_gpu< P >

Holds the computed moments on the GPU.

Stores the data for each moment after it has been computed, can hold either the hierarchical coefficients or the interpolation values.

The returned gpu::vector objects work similar to std::vector, they have a .data() method that returns a raw-pointer to the data and .size() that returns int64_t value. Individual entries cannot be dereferenced from the CPU.
